# Data Preprocessing & Preparation Pipeline 🚀

This repository contains **Lab 1 (TP1)** focused on **Data Preprocessing and Preparation** techniques using Python, Pandas, and NumPy. Clean and well-structured data is essential for building accurate Machine Learning models.

---

## 📌 Objectives

- Load raw datasets into Pandas DataFrames.
- Perform Data Cleaning (handling missing values, dropped unnecessary columns, and removing duplicates).
- Detect and treat statistical outliers using the **Interquartile Range (IQR)** method.
- Encode categorical features and normalize numerical variables.
- Convert cleaned DataFrames to NumPy arrays for machine learning pipelines.

---

## 🛠️ Tools & Technologies Used

- **Python 3.x**
- **Pandas** for data manipulation and analysis
- **NumPy** for numerical computations
- **VS Code** with Jupyter Extension
